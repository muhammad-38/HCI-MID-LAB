# Evaluation Plan — PolyLine Editor (Phase 3)

## Goal
Evaluate learnability, efficiency, and error rate for draw/edit tasks.

## Participants
3–5 students familiar with basic drawing tools.

## Tasks
1. Create a polyline with 5 points and finish it.
2. Move one specific vertex.
3. Delete an incorrect vertex.
4. Insert a point on a segment.
5. Save to JSON and load it back.
6. Refresh redraw.
7. Quit/exit.

## Metrics
- Time-to-complete each task
- Number of errors (wrong point moved/deleted)
- Number of times help overlay opened
- Subjective rating (1–5) for ease of use

## Success criteria
- Users complete tasks without external guidance within 2 minutes after reading help.
